## Dataset is separate

The maintainer states the event dataset is original work authored using their own algorithms. No public data files or data license have been supplied; dataset license **not yet selected**. The code `LICENSE` intentionally excludes separately licensed or unpublished datasets. Before the first data publication, record a suitable open-data license and attribution terms, then update the README, release manifest, notices and documentation. See [DATA_PROVENANCE.md](DATA_PROVENANCE.md).
